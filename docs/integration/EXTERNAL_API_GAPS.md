## 3. 対応方針

- 上記の未確認項目について、相手方(代理店システム運営・AIアート教室運営)へ正式に
  確認を依頼する。
- 確認が取れるまでは、`AgencyReferralClient`・AIアート教室固有の付与ロジックの
  **実装計画の作成**のみを行い、実コードの実装は行わない(推測実装の禁止)。
- 確認が取れ次第、各計画書の「対象ファイル」「API変更」等を実際の仕様に合わせて更新し、
  実装に着手する。
