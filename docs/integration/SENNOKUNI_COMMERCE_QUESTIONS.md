# 千ノ国マーケット様へのご確認（カード・ポイント連携）

`source_system_key` は **`sengoku-market` で承知しました。** この値はすでに弊社側で登録・
許可済みですので、**貴社の送信値を変更していただく必要はございません。**

接続を進めるにあたり、**3点だけご確認をお願いします。** いずれも短くご回答いただければ、
弊社側の登録作業に入れます。

## ご質問1【必須】`metadata.entitlement_type` に入れる値

弊社では商品の種類を `metadata.entitlement_type` で判別し、**種類ごとに別の扱い**を
しています（表示の出し分け、有効期限の有無など）。受け付ける値は次の2つです。

| 値 | 用途 |
|---|---|
| `membership_pass` | 会員証・会員券 |
| `digital_collectible` | コレクションカード |

**貴社からお送りいただくのは、どちらになりますでしょうか。**

- **`membership_pass` のみ** → このままお送りいただけます。弊社の追加作業はありません
- **`digital_collectible` も送る**（会員証とカードの2種類を扱う） → 弊社側で受け入れ設定を
  追加します。**1行の変更で済みますので、その旨だけお知らせください**

お伺いしている理由は、弊社が把握している情報が2通りあるためです。「会員証」としてお話を
いただいている一方、「NFTとして販売している」ともお聞きしており、**1種類なのか2種類なのか**
が判断できておりません。

### あわせてお願い

**`entitlement.granted` のサンプルJSONを1件**いただけますと、上記を含めて確実に確認できます。
実データでなくて構いません。弊社が必須としている項目は次の4つです。

```json
{
  "metadata": {
    "entitlement_type": "...",
    "asset_code": "...",
    "name": "...",
    "image_url": "https://..."
  }
}
```

## ご質問2【必須】ポイント付与の `product_code`

ポイント付与・取消（`reward.granted` / `reward.reversed`）については、弊社側で
**付与ルールの事前登録が必須**です。**未登録のまま送信されますと全件エラー（400）**に
なりますので、接続前に登録を済ませておきたく存じます。

ルールの識別子は、貴社がお送りになる `product_code` から決まります。

```
rule_code = "COMMON_EVENT_REWARD:" + product_code
```

**`product_code` にどのような値をお送りになりますでしょうか。**

- 付与の種別が複数ある場合（通常付与・キャンペーンなど）は、**種別ごとに分けていただくこと
  を推奨します。** 発行量が別々に集計でき、片方だけ停止することも可能になります
- `product_code` を送らない運用も可能です（その場合は `default` として登録します）

なお発行量の上限は、初期値として**1回あたり100,000 / 月あたり1,000,000**を設定する予定です。
上限に達した場合は400をお返しします。ご要望があればお知らせください（弊社の管理画面から
即時変更でき、システム停止は不要です）。

## ご質問3【必須】画像URLのドメイン

カード画像は URL でお送りいただく形になります（`metadata.image_url`、および任意で
`thumbnail_url`）。

**画像を配信されるドメインをお教えください。** 弊社側の許可リストへ登録します。
`https://www.sengoku-rr.com` からの配信でよろしいでしょうか。CDN等の別ドメインを
お使いの場合は、そちらもあわせてお知らせください。

URLの条件は次のとおりです。

- **HTTPS のみ**（http は受け付けません）
- **SVG は受け付けません**（PNG / JPEG / WebP をお使いください）
- URL長は2,048文字以内

## 弊社からお渡しする値・お預かりする値

ご質問ではありませんが、あわせてご確認ください。

### 弊社からお渡しします

| 項目 | 値 |
|---|---|
| 受取ページURL（`wallet_claim_web_base_url`） | `https://sennokuni-wallet.com` |
| 共通イベント署名鍵（Key ID / Secret） | 発行してお渡しします |

- **受取ページURL**: 最終的に利用者が開くURLが `https://sennokuni-wallet.com/claim/{token}`
  となれば正しい設定です。貴社側で `/claim/` を付加される実装でしたら上記の値を、
  パスまで含めた値が必要でしたらお知らせください
- **署名鍵**: 貴社が弊社へイベントを送信される際に使う鍵です。`entitlement.granted` /
  `entitlement.revoked` / `reward.granted` / `reward.reversed` を許可して発行します。
  **Secret は発行時の一度しか平文でお渡しできません**（弊社側も暗号化保存のみで、生の値を
  再取得できない設計です）

### お預かりします

| 項目 | 備考 |
|---|---|
| 受取確認API用 Key ID / HMAC Secret（`wallet_claim_inbound_*`） | 貴社の管理画面で生成された値 |

弊社から貴社の受取確認APIを呼び出す際に使用します。

**受け渡し方法は別途ご相談させてください。** 双方の Secret とも、メール本文への平文記載は
避けたく存じます。
