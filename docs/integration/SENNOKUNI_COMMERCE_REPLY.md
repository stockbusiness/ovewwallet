## 3. ご回答への確認

### 3-1. 受取人の特定 → 1点だけご確認ください

`common_user_id` 未解決の間は送信を保留し、解決後に自動送信、という設計は
**弊社側の想定と合っています。**

**1点、エラーコードの確認をお願いします。**
`common_user_id` は解決済みだが**ウォレット側にアカウントが紐付いていない**場合、
弊社は **404 Not Found** を返します（400ではありません）。貴社の再試行対象に
404 が含まれているかご確認ください。

**あわせてご相談です。** 貴社の再試行は「5分→10分→20分→40分→60分の最大5回」との
ことですので、**約2時間15分で手動確認対象**になります。

ところが、この経路で404になるのは「**共通顧客HUBには登録済みだが、まだウォレットに
登録していない**」方です。ウォレット登録が数日後になることは十分あり得ます。

- 再試行の間隔をもっと長く取る（例: 1日1回を数日間）
- あるいは手動確認対象になったものを、後から一括で再送できる導線を用意する

このどちらかをご検討いただけると、取りこぼしが減ります。**弊社側は同じ `event_id` で
何度お送りいただいても二重に付与しません**（冪等）ので、再送は安全です。
