# ロードマップ (次に進めるための作業手順)

「OVEウォレット 今後の実装・運用指示書 v1.0」12章「実装優先順位」に基づき、各計画書
(`docs/implementation/`, `docs/integration/`, `docs/test/`)に散らばっている作業を
**1本の順番付きチェックリスト**にまとめたものです。各項目には「誰が動く必要があるか」
(担当欄)と「状態」を明記しています。状態ラベルの意味は`docs/project-status.md`
「0. 状態表記ルール」参照。

## 担当の見方

| 担当 | 意味 |
|---|---|
| 開発 | コードを書けば進む項目。外部確認・アカウント作成は不要 |
| ユーザー | 業務判断、外部サービスのアカウント作成・契約確認など、ユーザー側の行動が必要 |
| 外部連携先 | 代理店システム・AIアート教室運営など、相手方からの回答待ち |

## 全体の流れ

```
P0 (本番安全性)
  → P1 (代理店紹介フロー完成)
  → P2 (AIアート教室連携完成)
  → P3 (限定公開)
  → P4 (公開後の価値利用、P0-P3完了後に要件定義)
```

開発側の作業の多くが「ユーザー」の行動待ちで`BLOCKED`になっています。全体を前に
