# 限定公開フェーズ試験計画

「OVEウォレット 今後の実装・運用指示書 v1.0」8章に基づく、代理店紹介3,000 OVE・
AIアート教室10,000 OVE連携が完成した後に行う10〜20人規模の限定試験の計画。

**前提**: 本計画はP1(代理店紹介Phase 2完成)・P2(AIアート教室連携完成)が終わって
から実施するものであり、現時点(P0対応中)では試験の枠組みのみを整理し、実施はしない。

## 試験対象 (指示書8.1章)

- 新規ユーザー
- 既存ユーザー
- 紹介URL経由ユーザー
- 紹介URLなしユーザー
- AIアート教室参加者
- 管理者
- 代理店担当者

## 試験内容 (指示書8.2章)

| カテゴリ | 項目 |
|---|---|
| 認証 | LINEログイン、メールOTP |
| 紹介 | 紹介URL受付、OVEアカウント作成、ウォレット作成、3,000 OVE付与 |
| AIアート教室 | 10,000 OVE付与 |
| 台帳 | 取引履歴表示、重複登録防止、同時処理、取消、保留 |
| アカウント | アカウント復旧、アカウント統合 |
| 管理 | 管理者MFA、全セッション無効化、API停止 |
| 運用 | Outbox再送、バックアップ復旧 |

既存の自動テスト(jest e2e 91件・Playwright 7件)でカバーされている項目も多いが、
限定試験は**実際のユーザー・実際のLINEチャネル・実際の代理店/AIアート教室API**を
使った通し確認である点が異なる。自動テストのカバー状況は`docs/test-plan.md`参照。

## 公開判定条件 (指示書8.3章)

- 重大な情報漏えいがない
- 他人の残高・履歴を閲覧できない
- マイナス残高が発生しない
- 二重付与が発生しない
- 代理店紹介が正しく確定する
- 3,000 OVEが正しい対象にだけ付与される
- 10,000 OVEが実参加者だけに付与される
- 取消履歴が正しく残る
- 管理者操作が監査ログに残る
- 障害時に復旧できる
